# Automated Reconnaissance Project

## Project Overview

This project documents a practical cybersecurity reconnaissance exercise focused on information gathering and identifying publicly observable information about a target domain.

## Objective

To understand how reconnaissance techniques and security tools can be used to gather information about a domain and assess its externally visible attack surface.

## Tools and Technologies

- Gobuster – Directory and file enumeration
- WHOIS – Domain registration information
- DNS reconnaissance – DNS record discovery
- TLS/SSL analysis – Examination of TLS configuration

## Project Files

- `reports.txt` – Reconnaissance findings
- DNS Report – DNS information collected
- Gobuster – Enumeration results
- TLS Report – TLS assessment results
- WHOIS – Domain registration findings

## Methodology

1. Identify the authorized target domain.
2. Gather domain registration information.
3. Perform DNS information gathering.
4. Examine TLS configuration.
5. Perform authorized directory enumeration using Gobuster.
6. Document findings in reports.

## Learning Outcomes

- Understanding reconnaissance methodologies.
- Learning DNS and WHOIS information gathering.
- Practising directory enumeration.
- Understanding TLS security assessment.
- Improving technical reporting skills.

## Authorization and Disclaimer

This project is intended for educational purposes and authorized security assessments only. Active scanning and enumeration must only be performed against systems for which permission has been granted.

## Conclusion

This exercise helped develop practical knowledge of reconnaissance techniques, information gathering, and security assessment reporting.
